# ゼロウェイスト政策シミュレーター（自治体汎用版）

自治体のごみ排出・組成・コストの基準データを入力すると、可燃ごみ中の**生ごみ・プラスチック・紙類**の「発生抑制」「分別・資源化」が、以下の指標に与える効果をブラウザ上で試算できるツールです。

- リサイクル率（%）
- ごみ総排出量（t/年）・1人1日当たり排出量（g/人・日）
- 焼却等処理量・処理率、埋立最終処分量・処分率（推計）
- CO2排出削減量（t-CO2/年）
- 財政効果（処理費削減額）・食品ロス削減価値（参考値）

## 使い方

1. `index.html` をブラウザで開く（デプロイ済みのURLにアクセスするか、ファイルをダブルクリック）
2. **① データ入力** タブに自治体の基準データを入力する
   - 「サンプル読込」ボタンで横浜市・令和5年度の実績データを投入して動作を確認できます
   - 人口・排出量は環境省「一般廃棄物処理実態調査」の調書や各自治体の清掃事業概要から転記できます
   - 組成割合はごみ組成調査（ごみ質分析）結果から転記します
3. **② シミュレーション** タブでスライダーを操作するか、プリセット／逆算モードを使う
   - 逆算モード：目標値（例：リサイクル率30%）から必要な削減率を自動算出
4. 計算根拠は **③ 計算方法** タブに明記しています
5. **④ 生ごみ循環（横浜）** タブでは、家庭コンポスト→コミュニティコンポスト→マイクロモビリティ→農家マッチングという生ごみの地域内循環モデル（`compost.html`・単独でも開けます）を試算できます。実施エリア（横浜市全市＋18区）を選ぶと、市全体の生活系生ごみ削減率・CO2削減・関係人口・経済循環効果を確認できます

## データの保存と共有

- 入力内容はブラウザの localStorage に自動保存されます（**サーバーには一切送信されません**）
- 「JSONエクスポート／インポート」で入力データをファイルとして共有できます

## 技術構成

- 静的HTMLのみ（外部ライブラリ・外部通信なし）。`index.html`（本体）と `compost.html`（生ごみ循環シミュレーター、タブ④からiframe表示）の2ファイル構成で、静的ホスティングにそのまま置けます
- ビルド不要。Render / Netlify / GitHub Pages 等では公開ディレクトリをリポジトリルート（`.`）に設定してください

## 免責

本ツールは政策検討用の簡易シミュレーションです。CO2係数は環境省の一般的係数（廃プラ焼却 2.77 t-CO2/t、バイオマス起源はカーボンニュートラル扱い等）を既定値としており、資源化処理単価・食品価値等の仮定値とあわせて、すべて設定画面から変更できます。試算結果の利用は自治体の実情に照らして判断してください。
