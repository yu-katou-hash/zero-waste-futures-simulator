# Zero Waste Futures Simulator（ゼロウェイスト政策シミュレーター・自治体汎用版）

自治体のごみ排出・組成・コストの基準データを入力すると、可燃ごみ中の**生ごみ・プラスチック・紙類**の「発生抑制」「分別・資源化」が、以下の指標に与える効果をブラウザ上で試算できるツールです。

- リサイクル率（%）
- ごみ総排出量（t/年）・1人1日当たり排出量（g/人・日）
- 焼却等処理量・処理率、埋立最終処分量・処分率（推計）
- CO2排出削減量（t-CO2/年）
- 財政効果（処理費削減額）・食品ロス削減価値（参考値）

## 使い方

1. `index.html` をブラウザで開く（デプロイ済みのURLにアクセスするか、ファイルをダブルクリック）
2. **① データ入力** タブに自治体の基準データを入力する
   - 「サンプル読込」ボタンで横浜市・令和5年度の実績データを投入して動作を確認できます
   - 人口・排出量は環境省「一般廃棄物処理実態調査」の調書や各自治体の清掃事業概要から転記できます
   - 組成割合はごみ組成調査（ごみ質分析）結果から転記します
3. **② シミュレーション** タブでスライダーを操作するか、プリセット／逆算モードを使う
   - 逆算モード：目標値（例：リサイクル率30%）から必要な削減率を自動算出
4. 計算根拠は **③ 計算方法** タブに明記しています
5. **④ Yokohama Urban Food Loop（生ごみ循環・横浜）** タブでは、家庭コンポスト→コミュニティコンポスト→マイクロモビリティ→農家マッチングという生ごみの地域内循環モデル（`compost.html`・単独でも開けます）を試算できます。実施エリア（横浜市全市＋18区）を選ぶと、市全体の生活系生ごみ削減率・CO2削減・関係人口・経済循環効果を確認できます
6. **⑤ Less Plastic, More Picnic（プラ削減×ピクニック・横浜）** タブでは、マイボトル給水スポット・テイクアウト容器シェアリング・量り売り店舗を広げる「Less Plastic, More Picnic」施策のインパクトモデル（`picnic.html`・単独でも開けます）を試算できます。インフラ設置ポテンシャルの推計を前提に、市民参加率とインフラ整備率から環境（プラ削減・CO2）・社会（関係人口）・経済（市内消費シフト・焼却コスト削減）効果を確認できます

## データの保存と共有

- 入力内容はブラウザの localStorage に自動保存されます（**サーバーには一切送信されません**）
- 「JSONエクスポート／インポート」で入力データをファイルとして共有できます

## 技術構成

- 静的HTMLのみ（外部ライブラリ・外部通信なし）。`index.html`（本体）、`compost.html`（生ごみ循環シミュレーター、タブ④からiframe表示）、`picnic.html`（Less Plastic, More Picnic シミュレーター、タブ⑤からiframe表示）の3ファイル構成で、静的ホスティングにそのまま置けます
- `picnic.html` の原本は [harch-ce-intel](https://github.com/yu-katou-hash/harch-ce-intel) リポジトリの `scripts/less-plastic-more-picnic/simulator.html`（モデル詳細・ロードマップのドキュメントも同ディレクトリにあります）。モデルを更新した際は両リポジトリに反映してください
- ビルド不要。Render / Netlify / GitHub Pages 等では公開ディレクトリをリポジトリルート（`.`）に設定してください

## リデュースとリサイクル率の関係（2026-09-10）

**発生抑制（リデュース）は、その素材が既に資源回収されている分も同率で減らす**
モデルになっています（`compute()` の `recPrevTotal`）。そのため古紙のように
すでに高い割合で回収されている素材をリデュースすると、分子と分母が同時に減り、
**全体のリサイクル率は下がります。**

この連動は「資源回収量の成分内訳」（生ごみ資源化量・古紙回収量・プラ資源回収量）
を使います。**この欄が空だと連動が働かず、増減の向きが逆に出ます。**

横浜市サンプル・紙の発生抑制のみを動かしたときのリサイクル率:

| 紙の発生抑制 | 内訳あり（古紙15万t） | 内訳が空 |
|---|---|---|
| 0% | 33.27% | 33.27% |
| 20% | 31.51% | 33.43% |
| 50% | 28.28% | 33.69% |

空だと分母だけが減るので、リデュースするほど率が上がってしまいます。
そのため次の3点で知らせるようにしています。

1. 内訳が丸ごと空のときは、① データ入力タブの「要確認」に挙げる
   （任意項目だが、**入れないと結果の向きが変わる**ため必須項目と同じ扱い）
2. ② シミュレーションタブのKPIタイル直下に、リサイクル率の読み方を1行出す
   （`#rate-note`・`renderRateNote()`）
   - 率が下がったとき … なぜ下がるか＋総排出量・焼却量の減少量（青い帯）
   - 連動が外れているとき … **警告**（率が実際より高く出ている旨）
   - 連動が効いていて率が上がったとき … 連動分を添える
3. ③ 計算方法タブに「向きが変わる」旨を明記

**リサイクル率が下がることは、発生抑制の効果が無いことを意味しません。**
効果は総排出量・焼却量・CO2・処理経費で評価してください。廃棄物政策の
優先順位（リデュース＞リユース＞リサイクル）では発生抑制が最上位です。

### cehub.jp 版との関係

同じツールが Circular Economy Hub の会員限定ツール
（`cehub.jp/tools/zerowaste/`・テーマの `apps/zerowaste/app.php`）にもあり、
上記3点は両方に入れてあります。**計算式は同一です。**
意図的に違うのは開いたときの初期状態だけで、こちらは横浜市サンプルが
入った状態で開き、cehub.jp 版は空で開きます（自分の自治体のデータと
紛れないようにするため）。

## 免責

本ツールは政策検討用の簡易シミュレーションです。CO2係数は環境省の一般的係数（廃プラ焼却 2.77 t-CO2/t、バイオマス起源はカーボンニュートラル扱い等）を既定値としており、資源化処理単価・食品価値等の仮定値とあわせて、すべて設定画面から変更できます。試算結果の利用は自治体の実情に照らして判断してください。
